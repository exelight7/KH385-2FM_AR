# Days Arabic · تعريب 358/2 Days

مشروع مجتمعي لتعريب **KINGDOM HEARTS 358/2 Days — HD cutscene compilation** ضمن نسخة Steam من **KINGDOM HEARTS -HD 1.5+2.5 ReMIX-**.

**0.2.0: حوار اليوم السابع كاملًا — Number XIV، ثمانية مقاطع حوارية.** مع الدفعة السابقة أصبح الإجمالي 28 من 2,556 مقطعًا (1.10%). خط Segoe UI Bold بحروف عربية متصلة؛ العرض داخل اللعبة ما زال يحتاج تأكيدًا. بقية المقاطع بالإنجليزية. لا يشمل KH1 أو KH2 أو Re:coded.

![واجهة المثبت](docs/installer-preview.png)

## التنزيل والتثبيت

الإصدار التجريبي [v0.2.0](https://github.com/exelight7/KH385-2FM_AR/releases/tag/v0.2.0) متاح في صفحة الإصدارات بعد اكتمال البناء. المستودع والتنزيلات عامة بناءً على اختيار صاحب المشروع.

| النظام | التحميل |
|---|---|
| Windows — تثبيت | [تحميل EXE](https://github.com/exelight7/KH385-2FM_AR/releases/download/v0.2.0/Days-Arabic-Setup-0.2.0.exe) |
| Windows — إلغاء | [تحميل EXE](https://github.com/exelight7/KH385-2FM_AR/releases/download/v0.2.0/Days-Arabic-Uninstall-0.2.0.exe) |
| Linux x64 | [تحميل AppImage](https://github.com/exelight7/KH385-2FM_AR/releases/download/v0.2.0/Days-Arabic-0.2.0.AppImage) |

1. أغلق اللعبة. شغّل **Days-Arabic-Setup-0.2.0.exe** على Windows، أو **Days-Arabic-0.2.0.AppImage** على Linux مع Steam/Proton.
2. سيبحث البرنامج عن مكتبات Steam. إن لم يجد اللعبة، اختر مجلدها أو مجلد `Image`.
3. اضغط **تثبيت التعريب**. يحتاج المثبت نحو 6 غيغابايت حرة لحفظ النسخة الأصلية وتجهيز الملفات.
4. أعد تشغيل اللعبة بالكامل واختر لغة النص **English**. افتح **358/2 Days → Chapters → Number XIV (Day 7)**. أول حوار لزيمناس: **«أبشروا يا أصدقائي. اليوم يوم عظيم.»**

يمكن تثبيت 0.2.0 مباشرة فوق 0.1.0؛ يحتفظ البرنامج بالنسخة الأصلية نفسها. يتضمن اليوم السابع استقبال شيون ثم حديث روكساس الداخلي. محادثة آكسل التالية تقع في اليوم الثامن حسب جدول فصول اللعبة. أسماء الفصول وبطاقات العنوان المصورة تبقى بالإنجليزية.

على Linux امنح AppImage صلاحية التنفيذ من خصائص الملف، أو استخدم `chmod +x Days-Arabic-0.2.0.AppImage`. قد تحتاج توزيعتك مكتبة FUSE 2. المثبت نفسه يعمل محليًا؛ لا يشمل اللعبة أو Proton. توافق العرض داخل اللعبة على Linux لم يُختبر بعد.

## إلغاء التعريب

افتح **Days-Arabic-Uninstall-0.2.0.exe** واضغط **إلغاء التعريب**، أو استخدم الزر نفسه داخل المثبت/AppImage. يسترجع البرنامج ملفات `Mare.hed` و`Mare.pkg` الأصلية من `Image/.days-arabic-backup`. احتفظ بهذا المجلد حتى بعد الإلغاء لتسهيل إعادة التثبيت. لا تلغِ التعريب بحذف ملفات Mare.

إذا رفض البرنامج النسخة، فهو لا يعرف بصمات ملفاتها أو وجد تعديلًا آخر؛ لن يستبدلها. لا تجمع هذا الإصدار مع تعديل آخر على Mare. إن حدث انقطاع، افتح المثبت مجددًا بعد إغلاق اللعبة ليسترجع العملية السابقة. على Windows قد تحتاج «تشغيل كمسؤول» إذا كانت مكتبة Steam تمنع الكتابة.

## فحوص الإصدار

- إعادة قراءة وكتابة 92 ملف CTD أصليًا دون اختلاف في البايتات.
- 28 رسالة في `cthd000.ctd` و`cthd800.ctd`؛ 673 رسالة أخرى وكل المعرفات والتخطيطات محفوظة.
- تحقق مستقل: جدول الفصول → المشاهد → معرّفات الحوار يثبت تغطية 8/8 مقاطع اليوم السابع.
- تحديث النصوص الإنجليزية المكررة داخل جداول EXIA2 مع الحفاظ على التوقيت وباقي اللغات. استخدام هذا النص المضمن أثناء التشغيل لم يُحسم؛ يشمل الإصدار مساري النص.
- 81 شكلًا عربيًا؛ فحوص اتصال الحروف والحدود والعرض تمر في معاينة الأطلس.
- حفظ كل سجلات Mare الأصلية وعددها 2,024. إعادة استخراج الأصول الثمانية المعدلة ومطابقة SHA-256.
- اختبارات آلية للتثبيت والإلغاء والتكرار، ورفض الملفات الغريبة، وتلف الحزمة/النسخة الاحتياطية، وفشل الاستبدال واسترجاع العملية المنقطعة.
- **أكد المستخدم أن 0.1.0 أعلن نجاح التثبيت لكنه رأى الإنجليزية. بصمات التثبيت صحيحة، ومشهد استقبال شيون لم يكن مشمولًا في الإصدار السابق. لا نعد نجاح المثبت إثباتًا للعرض داخل اللعبة. 0.2.0 اختُبر على نسخة ملفات منفصلة فقط.**

## سجل العمل والمساهمة

النص المنطقي في [translation/first_dialogue.json](translation/first_dialogue.json)، والمسرد في [translation/days-glossary.md](translation/days-glossary.md). يجب إرفاق لقطة لأول الحوار داخل اللعبة قبل توسيع دفعات الحقن. لا تُرفع ملفات اللعبة الأصلية أو نسخها الاحتياطية إلى المستودع.

## البناء

داخل `installer`: نفّذ `npm ci` ثم `npm test`، ثم `npm run build:win` على Windows أو `npm run build:linux` على Linux. بعدها `node release.cjs` لتجهيز مشغّل الإلغاء والبصمات. الأدوات تُبنى أيضًا عبر GitHub Actions. أول بناء ناجح على `main` ينشر إصدارًا تجريبيًا برقم النسخة. الإصدارات القائمة لا تُستبدل؛ ارفع رقم النسخة لإصدار جديد. لا يعني نشر الإصدار اعتماد العرض داخل اللعبة.

حزمة `installer/patch` تضم فروق XOR المضغوطة ضد الكتل الأصلية فقط، بحجم صغير. تتطلب النسخة المطابقة من اللعبة ولا تتضمن اللعبة الكاملة. أدوات بناء النص من المصادر المحلية موجودة تحت `technical`؛ إعادة إنتاج الأطلس تتطلب النسخة الأصلية المثبتة، خط Segoe UI Bold، وأدوات الاستخراج.

## الشكر

استُخدمت أدوات [LittleBitUA](https://github.com/LittleBitUA/KINGDOM-HEARTS-LOCALIZATION-TOOL) لقراءة/كتابة CTD ومعلومات الخط، و[OpenKH](https://github.com/OpenKH/OpenKh) لترميز الأصول. لا يتضمن المستودع نسخًا من أدواتهما. الملكية الفكرية للعبة والعلامات والشخصيات تعود إلى أصحابها. مشروع مستقل غير تابع إلى Disney أو SQUARE ENIX.
