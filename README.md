# Days Arabic · تعريب 358/2 Days

تعريب مجتمعي لـ **KINGDOM HEARTS 358/2 Days — HD cutscene compilation** ضمن نسخة Steam من **KINGDOM HEARTS -HD 1.5+2.5 ReMIX-**.

**1.0.1: ضبط الخط والقوائم.** صغّرنا خط القائمة الرئيسية إلى حجم موحّد قريب من الأصل، وضبطنا خطوط الفصول والإضافات ومحاذاتها. صحّحنا قص وصلات الحروف في خطّي الحوار والقوائم، ورجّعنا **DEVELOPED BY** إلى الإنجليزية الأصلية. لم تُعدّل نصوص الترجمة في هذا الإصدار.

**2461 / 2461 نصًا** في تسعة ملفات CTD: الحوار والمقدمة والسرد والفصول والقوائم ويوميات روكساس والتقارير السرية وأوصاف الشخصيات. النصوص مطابقة بالبايت لـ1.0.0 الذي خضع لمراجعتين مستقلتين كاملتين مقابل الإنجليزية الأصلية، مع 11 تصحيحًا مقارنة بـ0.4.1. [تقرير الجودة ومصدر المراجعات](translation/v1.0.1/quality-report.json).

الحصر القديم **2556 = 2461 نصًا + 95 مفتاحًا تقنيًا للمشاهد**. تبقى المفاتيح حرفيًا كي تعمل اللعبة. نسبة 100% تخص النصوص المحصورة؛ الكتابات الزخرفية داخل بعض صور المشاهد، مثل WINNER وOPERATIONS CLOSED FOR VACATION، ما زالت بالإنجليزية. الشعارات والتترات الأصلية محفوظة. توجد **24 عبارة عربية في القوائم المصورة** بعد استعادة DEVELOPED BY.

الخط **IBM Plex Sans Arabic Medium** هو الملف نفسه المستخدم في KH2FM. أظهرت صور المستخدم في 1.0.0 تضخّم القوائم وانفصال بعض الحروف؛ عالج 1.0.1 حدود رسم الحروف وأحجام القوائم. **اعتماد العرض الجديد داخل اللعبة ما زال بانتظار التجربة.**

## التنزيل

الإصدار التجريبي [v1.0.1](https://github.com/exelight7/KH385-2FM_AR/releases/tag/v1.0.1). المستودع والتنزيلات عامة باختيار صاحب المشروع.

| النظام | التحميل |
|---|---|
| Windows — تثبيت | [Setup EXE](https://github.com/exelight7/KH385-2FM_AR/releases/download/v1.0.1/Days-Arabic-Setup-1.0.1.exe) |
| Windows — إلغاء | [Uninstall EXE](https://github.com/exelight7/KH385-2FM_AR/releases/download/v1.0.1/Days-Arabic-Uninstall-1.0.1.exe) |
| Linux x64 | [AppImage](https://github.com/exelight7/KH385-2FM_AR/releases/download/v1.0.1/Days-Arabic-1.0.1.AppImage) |

1. أغلق اللعبة ومشغّل المجموعة وشغّل المثبت. على Linux امنح AppImage صلاحية التنفيذ من خصائصه.
2. اختر مجلد اللعبة أو Image إن لم يعثر البرنامج على مكتبة Steam.
3. اضغط **تثبيت التعريب**. يحتاج إلى نحو 6 غيغابايت حرة للنسخ الاحتياطي وتجهيز الملفات.
4. أعد تشغيل اللعبة بالكامل واختر **English** للنص، ثم افتح **358/2 Days**.

يدعم التحديث المباشر من **0.1.0 و0.2.0 و0.3.0 و0.4.0 و0.4.1 و1.0.0** ويحفظ النسخة الأصلية نفسها. AppImage يوفر التثبيت والإلغاء لنسخة Steam/Proton، وقد تحتاج توزيعتك FUSE 2. عرض التعريب داخل اللعبة على Linux لم يُختبر بعد.

## الإلغاء والاسترجاع

افتح **Days-Arabic-Uninstall-1.0.1.exe** واضغط **إلغاء التعريب**، أو استخدم الزر نفسه داخل المثبت/AppImage. يسترجع البرنامج Mare.hed وMare.pkg من Image/.days-arabic-backup. احتفظ بهذا المجلد. يرفض المثبت البصمات غير المعروفة والتعديلات الأخرى. إن انقطعت العملية، افتحه مجددًا بعد إغلاق اللعبة. عند رفض صلاحية الكتابة في مكتبة Steam على Windows، استخدم «تشغيل كمسؤول».

## التحقق والنطاق

- ملفات الترجمة التسعة مطابقة لـ1.0.0؛ مراجعتاه موثّقتان في [التقارير الأصلية](translation/v1.0.0/reviews). لا ندّعي مراجعة لغوية جديدة في 1.0.1.
- فحص قصّ الحروف على عرض COD اختبر **1334 زوجًا متجاورًا** من النصوص لكل خط، بلا وصلات مكسورة في المعاينة الجديدة. [نتائج الفحص وحدوده](technical/verification/v1.0.1-font-rendering.json).
- أحجام القوائم المصورة قورنت بارتفاع الحبر الأصلي؛ حدود العناصر والهندسة وأبعاد الصور والشفافية والبكسلات خارج النصوص محفوظة. DEVELOPED BY وSQUARE ENIX مطابقان للأصل.
- 92 إعادة تركيب CTD دون اختلاف؛ حفظ المعرفات والتخطيطات والأوامر والأسطر الفارغة والمفاتيح التقنية الـ95. تحديث 1568 معرفًا داخل 121 جدول EXIA2 مع حفظ التوقيت واللغات الأخرى.
- إعادة استخراج الأصول الـ136 المعدلة ومطابقة SHA-256، مع حفظ سجلات Mare الـ2024 ومنها السجلات غير المعروفة الـ57. الفيديو الأصلي محفوظ دون إعادة ترميز.
- **23 اختبارًا** للمثبت، مع اختبار ترقية وإلغاء على نسخة كاملة منفصلة واسترجاع الأصل مطابقًا بالبايت. [نتيجة الاختبار الكامل](technical/verification/v1.0.1-full-archive.json).

تشمل الملفات المشتركة بعض أسماء فصول Re:coded وأوصاف شخصياته ورسائل اختيار الألعاب. قصة Re:coded وقصة KH1 وKH2 خارج النطاق. اكتمال النصوص لا يقيس الصور المتبقية أو الاعتماد البصري.

تم تركيب **1.0.1** على نسخة صاحب المشروع بعد اختبار النسخة المنفصلة؛ [سجل التثبيت](technical/verification/v1.0.1-install.json) يثبت تطابق الحزمة وسلامة النسخة الأصلية الاحتياطية. لم تُشغّل اللعبة تلقائيًا. سبب ملاحظة اختلاف جودة المشاهد لم يُحسم؛ [فحص الفيديو](technical/verification/video-integrity.json) و[فحص الأرشيف الحالي](technical/verification/v1.0.1-archive.json) يثبتان حفظ البيانات الأصلية.

بناء حزم Windows وLinux ونشر التنزيلات جارٍ. تُضاف سجلات البناء والتحقق بعد اكتمالها.

## المساهمة والبناء

النصوص في [translation/v1.0.1](translation/v1.0.1)، والقواعد في [STYLE.md](translation/full/STYLE.md). لا ترفع ملفات اللعبة الأصلية أو النسخ الاحتياطية.

داخل installer: نفّذ npm ci ثم npm test ثم npm run build:win أو npm run build:linux، وبعدها node release.cjs. يبني GitHub Actions الحزمتين وينشر إصدارًا تجريبيًا عند تغيير رقم النسخة. [تعليمات بناء الأصول](technical/README.md).

حزمة installer/patch تحفظ فروق XOR وتحتاج النسخة المطابقة من اللعبة. خط Plex مرفق بترخيص SIL OFL داخل font-rtl/fonts/OFL.txt والتطبيق.
