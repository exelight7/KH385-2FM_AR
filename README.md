# Days Arabic · تعريب 358/2 Days

مشروع مجتمعي لتعريب **KINGDOM HEARTS 358/2 Days — HD cutscene compilation** ضمن نسخة Steam من **KINGDOM HEARTS -HD 1.5+2.5 ReMIX-**.

**الحالة: دفعة تجريبية؛ 24 مقطعًا من أصل 2,556 مقطعًا ظاهرًا (0.94%). لم تُعتمد المعاينة داخل اللعبة بعد.** يشمل الإصدار أول حوار وخط Segoe UI Bold بحروف عربية متصلة. بقية المقاطع بالإنجليزية. لا يشمل KH1 أو KH2 أو Re:coded.

## التنزيل والتثبيت

عند نشر إصدار، تجد الملفات في [الإصدارات](https://github.com/exelight7/KH385-2FM_AR/releases). المستودع والتنزيلات عامة بناءً على اختيار صاحب المشروع.

1. أغلق اللعبة. شغّل **Days-Arabic-Setup-0.1.0.exe** على Windows، أو **Days-Arabic-0.1.0.AppImage** على Linux مع Steam/Proton.
2. سيبحث البرنامج عن مكتبات Steam. إن لم يجد اللعبة، اختر مجلدها أو مجلد `Image`.
3. اضغط **تثبيت التعريب**. يحتاج المثبت نحو 6 غيغابايت حرة لحفظ النسخة الأصلية وتجهيز الملفات.
4. اختر لغة النص **English** في اللعبة، وشغّل Days من البداية.

على Linux امنح AppImage صلاحية التنفيذ من خصائص الملف، أو استخدم `chmod +x Days-Arabic-0.1.0.AppImage`. قد تحتاج توزيعتك مكتبة FUSE 2. المثبت نفسه يعمل محليًا؛ لا يشمل اللعبة أو Proton. توافق العرض داخل اللعبة على Linux لم يُختبر بعد.

## إلغاء التعريب

افتح **Days-Arabic-Uninstall-0.1.0.exe** واضغط **إلغاء التعريب**، أو استخدم الزر نفسه داخل المثبت/AppImage. يسترجع البرنامج ملفات `Mare.hed` و`Mare.pkg` الأصلية من `Image/.days-arabic-backup`. احتفظ بهذا المجلد حتى بعد الإلغاء لتسهيل إعادة التثبيت. لا تلغِ التعريب بحذف ملفات Mare.

إذا رفض البرنامج النسخة، فهو لا يعرف بصمات ملفاتها أو وجد تعديلًا آخر؛ لن يستبدلها. لا تجمع هذا الإصدار مع تعديل آخر على Mare. إن حدث انقطاع، افتح المثبت مجددًا بعد إغلاق اللعبة ليسترجع العملية السابقة. على Windows قد تحتاج «تشغيل كمسؤول» إذا كانت مكتبة Steam تمنع الكتابة.

## فحوص الإصدار

- إعادة قراءة وكتابة 92 ملف CTD أصليًا دون اختلاف في البايتات.
- 24 رسالة معدلة فقط في `cthd000.ctd`؛ 332 رسالة أخرى وكل المعرفات والتخطيطات محفوظة.
- 76 شكلًا عربيًا و178 وصلة حروف؛ أقل شدة حبر في الوصلات 125/128 في معاينة الأطلس.
- حفظ كل سجلات Mare الأصلية وعددها 2,024. إعادة استخراج الأصول الثلاثة المعدلة ومطابقة SHA-256.
- اختبارات آلية للتثبيت والإلغاء والتكرار، ورفض الملفات الغريبة، وتلف الحزمة/النسخة الاحتياطية، وفشل الاستبدال واسترجاع العملية المنقطعة.
- **لم يتم تثبيت الحزمة في اللعبة أثناء تجهيز المشروع. لم تُختبر المزامنة والموضع والخط داخل اللعبة بعد.**

## سجل العمل والمساهمة

النص المنطقي في [translation/first_dialogue.json](translation/first_dialogue.json)، والمسرد في [translation/days-glossary.md](translation/days-glossary.md). يجب إرفاق لقطة لأول الحوار داخل اللعبة قبل توسيع دفعات الحقن. لا تُرفع ملفات اللعبة الأصلية أو نسخها الاحتياطية إلى المستودع.

## البناء

داخل `installer`: نفّذ `npm ci` ثم `npm test`، ثم `npm run build:win` على Windows أو `npm run build:linux` على Linux. بعدها `node release.cjs` لتجهيز مشغّل الإلغاء والبصمات. الأدوات تُبنى أيضًا عبر GitHub Actions. أول بناء ناجح على `main` ينشر إصدارًا تجريبيًا برقم النسخة. الإصدارات القائمة لا تُستبدل؛ ارفع رقم النسخة لإصدار جديد. لا يعني نشر الإصدار اعتماد العرض داخل اللعبة.

حزمة `installer/patch` تضم فروق XOR المضغوطة ضد الكتل الأصلية فقط، بحجم نحو 49 KiB. تتطلب النسخة المطابقة من اللعبة ولا تتضمن اللعبة الكاملة. أدوات بناء النص من المصادر المحلية موجودة تحت `technical`؛ إعادة إنتاج الأطلس تتطلب النسخة الأصلية المثبتة، خط Segoe UI Bold، وأدوات الاستخراج.

## الشكر

استُخدمت أدوات [LittleBitUA](https://github.com/LittleBitUA/KINGDOM-HEARTS-LOCALIZATION-TOOL) لقراءة/كتابة CTD ومعلومات الخط، و[OpenKH](https://github.com/OpenKH/OpenKh) لترميز الأصول. لا يتضمن المستودع نسخًا من أدواتهما. الملكية الفكرية للعبة والعلامات والشخصيات تعود إلى أصحابها. مشروع مستقل غير تابع إلى Disney أو SQUARE ENIX.
