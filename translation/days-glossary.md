# مسرد Days

الأسماء المتوافقة مع مسرد KH المعتمد في المشروع المحلي:

| الأصل | العربية |
|---|---|
| Roxas | روكساس |
| Axel | آكسل |
| Xemnas | زيمناس |
| Xion | شيون |
| Keyblade | الكيبليد |
| Number XIV | رقم أربعة عشر |
| Got it memorized? | حفظتها؟ |

«شيون» اختيار لهذه الدفعة التجريبية، ويُوحّد في جميع رسائل Days. النص داخل اللعبة يستخدم علامات الترقيم الموجودة في الخط الأصلي؛ تحسين الترقيم العربي خطوة لاحقة بعد اعتماد العرض داخل اللعبة.
